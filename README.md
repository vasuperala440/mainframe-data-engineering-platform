# Mainframe-to-Cloud Data Engineering Platform

## Business Problem

A financial organization currently processes customer,
account, and transaction data using a legacy mainframe system.

The mainframe generates batch files containing customer,
account, and transaction information.

The objective of this project is to build a modern data
engineering platform that ingests the legacy data,
performs data transformation and quality validation,
and makes the data available for analytics.

## Objectives

- Ingest mainframe-style fixed-width files
- Build a Python ingestion pipeline
- Process data using PySpark
- Implement data-quality checks
- Store processed data in Parquet
- Build a dimensional data warehouse
- Orchestrate pipelines using Airflow
- Implement incremental processing
- Containerize the platform using Docker
- Design a cloud architecture using AWS
